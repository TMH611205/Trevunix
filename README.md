## Tải về và sử dụng

1. Tải **[Trevunix.exe](https://github.com/TMH611205/Trevunix/releases/latest/download/Trevunix.exe)**. Không cần cài đặt, không cần cài .NET.
2. Mở file và chọn **Yes** khi Windows hỏi quyền Administrator.
3. Nếu Windows SmartScreen báo _"Windows protected your PC"_, chọn **More info** rồi **Run anyway**. Cảnh báo này xuất hiện vì file chưa được ký số.

Mỗi lần mở, Trevunix tự kiểm tra và tải bản mới. Giữ nguyên tên file `Trevunix.exe` để tính năng này hoạt động.

## Tính năng

- **Tối ưu**: tinh chỉnh quyền riêng tư, hiệu năng, chơi game, File Explorer và thanh tác vụ. Mọi thay đổi đều hoàn tác được.
- **Dọn dẹp**: file tạm, báo cáo lỗi, bộ nhớ đệm Windows Update, trình duyệt, ứng dụng và Thùng rác.
- **Phân tích dung lượng ổ đĩa**: thư mục và tệp lớn nhất, dung lượng theo loại tệp.
- **Ứng dụng & Khởi động**: bật/tắt chương trình chạy cùng Windows, gỡ ứng dụng cài sẵn.
- **Công cụ hệ thống**: giám sát CPU/RAM/mạng, tiến trình, sửa lỗi Windows (SFC, DISM), đổi DNS, sức khoẻ ổ đĩa.

Yêu cầu: Windows 10 hoặc 11 (x64).
